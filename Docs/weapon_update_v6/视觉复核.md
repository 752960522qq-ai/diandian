# V6 自然动作与肩部修正验收

## 结果与修改范围

林叙 M870 跑步的左肩夹细已定位并修正：原握持适配强制左手朝向，再把大幅轴扭转分配给前臂和上臂；这种旋转被烘进衍生动作。最终方案保留原跑步的自然腕向，关闭这两级额外轴扭转，不修改人物形体、骨长或蒙皮权重。

只取消上臂扭转的早期方案会把夹细转移到肘部，已弃用。最终方案同时检查肩、肘、腕与托枪关系，不以单一碰撞或蒙皮指标代替视觉判断。

修正限定在林叙、军装、背心的 M870 跑步。肩骨、颈头、躯干、腿、右臂、枪轨迹和动作时长不变；左臂与腕指改变，林叙左肘/腕最大位移约5厘米，两位抵抗军约5–7厘米。不能表述成手部路径完全未动。各人其余27条新装备动作未改，旧五枪原动作未改。

点点、知更的 M870 跑步另与原 M97 同相位复核，32张左右肩前后视未发现同型明显夹细，保持其最终D绑定，不套用男角色修正。

## 保留的局限

- 原枪与手枪的部分换弹是通用示意手势，左手会在枪体或弹匣上方活动，不是逐枪精确机械拆装；与原动作基线一致，没有为追求“零问题”重写动作。
- M870换弹早段约0–0.1秒，后视枪托靠近或少量进入右腋衣服；辅助掌少数指节略松、部分手套/皮肤与枪体轻微相交仍保留，以原动作与自然关节优先。
- 原97式的Run/Before最终姿态基本相同，原始基线亦如此；保留既存比较行为。
- 本环境未完成实时浏览器/WebGL、手机设备或正式游戏混合控制器验收，不宣称所有视角绝对无问题。可通过更新后的林叙预览继续核验实际显示效果。
