# 五人人物武器与动作修正 · V6

本版已补做林叙全部界面动作的前、侧、后视复核，并修正M870跑步左肩夹细。详细采样范围、保留的原动作局限与未测项见《视觉复核》。

本包按最新反馈重新修正：动作以原始片段为基础，自然肩肘腕指优先，允许少量接触穿插。不沿用 V5 为压低碰撞数值而大幅改姿的方案。

## 本次修改

- M870 总长精确 **1.000000米**。机匣、枪托、护木与对应小件横向缩至 **0.88**，总宽由68.452毫米降为60.238毫米；圆枪管、管帽保持原截面，高度211.569毫米不变。泵独立行程75毫米，部件装配已检查。
- 点点、知更、林叙V4、军装及背心抵抗军恢复原动作身份、时长和主要身体轨道。换弹恢复原下枪/释放手，射击恢复原后坐，低持不再强制变成平瞄。
- 92、54使用对应精修模型。64独立绑定，沿用54姿势来源，撤销造成竖拇的大角度强制覆盖。手枪跑步统一采用原RifleRun低持身体与原手枪挂载适配，不采用贴脸高持混轨。
- QBU85保留原枪、原动作，不用SVD替代。原人物、林叙短颈、其他原枪和动作保持不变；唯一新增的原空手动作修改是用户要求的林叙Walk小修。
- 林叙手枪Idle恢复原0.033秒静态源。V5曾把3.1秒身体运动压进去，产生30Hz抖动；已通过多帧率和不规则步长复核，不能只用30fps抽样判断。
- 林叙Walk仅平滑原贴地补偿折角，最大位置变化3.30毫米，原旋转、XZ、步频和正常上下起伏保留。最终起伏仍约4厘米，不是把走路改为平移。候选实测最低鞋底净空2.671毫米，无新增水平脚滑。
- 林叙、军装、背心的M870跑步取消强制握持方向引出的两级额外轴扭转，保留原跑步自然腕向，纠正左肩夹细。改动限于左臂和腕指；肩骨、颈头、躯干、腿、右臂、枪轨迹与时长不变。林叙左肘/腕最大位移约5厘米，两位抵抗军约5–7厘米，不能说双手轨迹完全未动。两女经同相位肩部对照未见同型塌陷，保持原绑定。

## 安装与兼容

这是**完整的当前增量文件覆盖包**，不是整个仓库。主库基线为 `95bab506c0e01e04c7818f7e0f5001ad3a105c14`；动作原始对照为 `81d5a485bbac0d7dabdffe5252a32537fd74b9fc`，两者在相关人物/武器/动作文件上相同，仅新增场景和LFS声明。

也支持已安装上一份V5修改包的已知文件指纹（完整包SHA：`6218691f23a4867229747d25489a16cb1087449ab1432ed48ea069a7aec449c2`）。不要求先安装V5。未知本地编辑不会被强行覆盖。

1. 使用完整仓库并获取Git LFS实体资产。先备份项目。
2. 将ZIP解压到仓库目录以外。执行 `python apply_update.py /path/to/diandian`，默认只校验，不写入。
3. 无冲突后执行 `python apply_update.py /path/to/diandian --apply`。安装器先核对全部文件，再写入；重复安装会跳过相同文件。
4. 安装后会给出备份目录及回滚命令。回滚也会拒绝覆盖安装后的新编辑。

包根 `manifest.json` 记录基线、兼容的V5指纹及全部输出SHA-256。文中工程路径均以安装后的仓库为根；未安装时在ZIP的 `files/` 下查找。旧V5骨包或旧报告若已存在可继续留作历史，本次运行不使用它们。

## 网站与骨包使用

四个预览站均是静态站：在仓库运行 `python -m http.server 8080`，打开 `web/motion-labs/` 下的 `diandian-classic-motion-lab`、`zhigeng-motion-lab`、`linxu-motion-lab` 或 `resistance-motion-lab`。Three.js/加载器位于基线各站的 `vendor/`，不依赖外部CDN。

新四枪的跑步不进入旧“原始跑步比较”分支；旧枪/空手的原比较功能保留。新资源使用V6缓存标识。

两女的导出在各站 `assets/refined_equipped_v6/`；三人的导出在 `assets/characters/weapon_update_v6/<角色>/`。枪体/泵件轨迹必须与同角色骨包一起使用，两女还必须应用对应的胸部蒙皮伴随数据。只导入骨骼动画不等于完整网页效果。

两女各42条导出包括27个装备动作组合及15条俯仰采样（含与水平层重叠的采样），不是42种全新动作。三人各28条。连续滑杆、混合与原运行时求解仍须按配套逻辑接入，不能把离散骨包当作任意姿态的完整替代。

## 验收范围与边界

- 已做原动作同条件多视角/连帧对照、运行时连续取样、原枪与无装备回归、新旧枪切换/暂停/seek/单次重播状态检查、骨包回读及可行的Godot原生骨架检查。具体数量与误差见最终验收说明及随包报告。
- 两女骨包关键采样点回读误差小于1.52×10⁻⁷；帧间插值的最远骨点差约5.9毫米，不能宣称任意时刻完全一致。
- 辅助掌少数手指略松、局部皮肤/手套与枪体少量相交仍保留。按自然动作优先，不再为数值归零反扭手腕或大幅改肩臂。
- 新M870的Fire与Pump按一次性动作处理。原后坐终帧比首帧高属于原动作语义，不等同循环抖动。上射峰值约68.3°与原M97一致。其他枪保留各自原播放规则，不能把全部射击片段概括为单次播放。
- 手枪跑步/换弹是原通用片段适配；没有新制作专用弹匣拆装、弹药或逐发装填仿真。
- 部分原枪与手枪换弹包含左手在枪/弹匣上方示意的通用手势；M870换弹早段后视有枪托靠近或少量进入右腋衣服的交叠。这些不是精确机械换弹演示，未为消除轻微交叠而重写原动作。
- 本环境浏览器启动受限制，不能称实时WebGL/手机UI已验收。离线真实蒙皮连帧与CPU状态测试不能替代最终浏览器核验。
- 原生Godot检查是隔离骨架播放/导入验证，不代表正式游戏控制器、全部蒙皮伴随数据和混合逻辑已接入；未做Android性能测试或正式发布。

## 来源、重建与许可

安装现成文件不需要运行生成器。重建应从**已应用本包的完整工程副本**开始；`install.py`等辅助脚本不是干净基线的一键安装器。工具的写入型生成命令只在备份副本使用。

需要原始对照时准备独立基线：`git worktree add ../character_adapt_baseline 81d5a485bbac0d7dabdffe5252a32537fd74b9fc`，在其中执行 `git lfs pull`。工具可用环境变量/参数指定基线目录，详见各目录说明。Node验证需Three.js 0.180.0；Python/Blender/Godot依赖按对应工具说明配置。历史V5对照是可选输入，不是正式预览运行依赖。

M870可由 `python tools/weapon_v6_scale/thin_m870_body.py --root "$PWD"` 从包内原精修源重建；幂等性已验证，不会每次重复压薄。原精修源、材质、UV与BIN保留，游戏版仅做有说明的坐标/尺度和分件横向调整。
