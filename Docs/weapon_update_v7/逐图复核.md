# 八张截图逐图复核

判定以用户原图、原模型骨架与实际蒙皮共同为依据。红圈包含遮挡时，不把二维重叠直接当成三维穿插；也不把指骨角度合格当作表面自然的证明。

1. IMG_20261109_234634.jpg，林叙 QCQ171，待机约 4.28 秒。
   - 主要问题：右手背/腕部黑线和挤压，来自林叙拇指根极端参考旋转与手/前臂混合权重。隐藏枪后仍有同一黑线。
   - 修复：林叙专用拇指根回收，另按实际关节应用手指过折限制。
   - 区分：截图相位及另四相位的右臂/枪面检测没有交叉；枪托邻近袖口不应靠大幅降肘“修复”，那反而产生真穿插。

2. IMG_20261109_234612.jpg，林叙 QSZ92，高持待机约 0.02 秒。
   - 共同问题：新手枪双手高持配合不合适，指尖相抵或支撑掌位置失配。
   - 修复：三名男性在 QSZ92、54 式、64 式高持待机/行走中，支撑手沿枪局部横向平移 40mm，保留腕方向和自然肘平面。
   - 补充手指要求：三种手枪瞄准/射击的整条食指也重新协调，不只消除末节轴扭；军装 QSZ92 单独增加 4mm 腕前移，枪世界轨迹保持。

3. IMG_20261109_234554.jpg，林叙 M870，拉泵末帧约 0.73 秒。
   - 共同问题：原轴扭分配使左肩/上臂塌陷，枪托靠近下巴。
   - 修复：三名男性的六个肩托相关动作取消有害的上臂/前臂轴扭分配，保持原手腕方向；枪和双腕整体下移 35mm，使用保肘平面的双骨求解，原拉泵节奏与枪方向不变。
   - 验证：三角色中段与末帧正/侧/俯视，林叙向上/向下瞄准多视图；未见所抽帧中原有肩部翻折或明显下巴穿入。向上瞄准仍贴近面颊，不宣称任意镜头零遮挡。

4. Screenshot_2026-11-09-23-45-08-332_com.android.chrome.jpg，背心抵抗军 QBU85，待机约 6.49 秒，无红圈。
   - 作为不同角色的参照图。其拇指根并非林叙相同的极端翻转，保留角色独立适配。
   - 两种抵抗军确有其他手指末节过折组合，按角色/武器/动作限幅，不直接复制林叙的根指修正。

5. IMG_20261109_234647.jpg，林叙 97 式，待机约 6.78 秒。
   - 问题包含拇指根/腕背挤压，以及枪托下缘穿过右前臂，后者经过实际表面交叉确认。
   - 林叙：枪局部 Z 转 −6°，参考右掌相对枪 Z 转 −12°，补偿食指和小指根；原肘平面与枪平移保留。
   - 军装：独立使用右肘平面 −30°、参考右掌相对枪 X 转 −20°，补偿食指根；枪角与偏移保留。背心仅有轻微邻接，保留原姿。
   - 验证：林叙待机 17 相位右臂连腕区未检出枪面交叉，左臂五相位未检出；军装待机 17 相位在距腕 6cm 以外的主要前臂区域未检出，腕部握持近邻仍有接触区相交。不能据此宣称三角色整只手零穿模。
   - 这项联合校正仅用于待机；其余 97 式动作保留原动作与本次通用手指修正，已检查切回待机没有姿态残留。

6. IMG_20261109_234703.jpg，林叙 QBU85，待机约 5.75 秒。
   - 个别问题：拇指根参考姿态导致腕背自体蒙皮挤压，而不只是枪身遮挡。
   - 修复：将该拇指根向原动作自然姿态回收 60%，保持枪和手腕轨迹。
   - 七个相位的拇指末节/尖端未检出枪面交叉，尖端至枪面约 5.6–13.6mm；指根包握接触仍存在。

7. IMG_20261109_234716.jpg，林叙 56-1，待机约 3.36 秒。
   - 同类腕背黑线。拇指根向自然原姿回收 50%，对应动作的拇指第二节上限 80°。
   - 七个相位的拇指末节/尖端未检出枪面交叉，尖端至枪面约 8.8–12.3mm。其他身体动作和枪轨迹保留。

8. IMG_20261109_234733.jpg，林叙 QBZ95，待机约 5.85 秒。
   - 个别问题：右肘/袖位置偏高，后托与袖口关系不自然。
   - 修复：右肘平面从 −140° 小调至 −130°，枪局部转 6°，肘垂直降低约 13mm。没有采用造成新穿插的大幅降肘方案。
   - 17 相位右臂和五相位左臂未检出枪面交叉；掌部目标仍吻合。该结果限于被测区域与相位。

## 共用手指修复与验收边界

旧五枪共 98 个明确的角色/武器/动作/指节修正项，61 相位共 5,978 个约束样本通过。M870 行走的右中指轴扭单独处理，保持指尖；新手枪则用按角色和武器确定的三节食指局部增量，保留原动作微小变化，避免把瞄准和射击冻结成一帧。

所有表面交叉数量都是相同网格的三角面统计，不代表穿透体积或人体软组织深度。允许合理的抓握接触和轻微重叠，优先移除明显反折、塌陷、压缩指尖和枪托穿主要前臂。旧 97 式部分其他动作的原有接触未被重做；本次不声称所有枪、所有动作、所有相机均无接触。
