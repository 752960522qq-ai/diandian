## 修复内容

### 共同问题

- 三名男性角色的旧枪手指存在不同的过折组合。按角色、武器、动作和具体指节设置 98 条修正，不对所有手指统一压直。
- QSZ92、54 式、64 式的高持待机/行走：支撑手沿枪局部横向调整 40mm，保持原手腕朝向、自然肘平面和原枪轨迹。
- 三种新手枪的瞄准/射击：先处理右食指末节原有约 121–145° 的多余轴扭，再按真实扳机表面联合调整三节食指，消除向上突出的压缩指尖。军装 QSZ92 额外将右腕沿枪前向平移 4mm，以适应较短手指；枪身世界轨迹不变。
- M870 行走：右中指第二节的过度轴扭减至 35°，补偿下一节以保留指尖位置。
- M870 的瞄准、平举/向上/向下、射击和拉泵：去掉导致左肩/上臂塌陷的轴扭分配，枪与双手在保留原方向和时间节奏的前提下下移 35mm，增加枪托与下巴间隙。跑动与换弹不受此项修改。

### 林叙个别问题

- QCQ171、97 式、QBU85、56-1、QBZ95 的右手背黑线，主要来自参考握持中拇指根被旋转到约 144–165° 后的混合蒙皮挤压，并非每一处都是枪身穿过手。将该拇指根向原始自然姿态适量回收；两种抵抗军不套用林叙专用校正。
- QBU85 的拇指根回收比例为 60%，其余四枪为 50%；56-1 的特定拇指第二节上限为 80°。需要以最终表面图判断抓握，不能只看角度数字。
- QBZ95 待机：小幅调整右肘平面和枪局部方向，枪转 6°，肘垂直降低约 13mm，保留原掌部接触。未采用会造成新穿插的大幅降肘方案。
- 97 式待机：林叙采用枪局部转角、掌部方向与食指/小指补偿的联合校正；军装使用独立的掌臂和食指补偿，背心保留原姿。修正截图所示枪托穿前臂，避免把一套参数套到三个不同模型。详细范围见《逐图复核》。

### 保留的自然边界

手指包握和衣袖可能存在接触区或轻微交叠，不宣称整只手、所有表面、所有相位都零穿插。扳机指采用整链协调而非单独压直末节。指腹与扳机、握把的接触区仍可能局部相交；军装 97 式腕部握持近邻也仍有接触区相交。已优先消除明显的反折、压缩指尖和枪托穿主要前臂。原动作的身体、头颈、腿部和帧时不作重做。

## 安装与回滚

1. 下载全部 V7 分卷和 V7 合并校验工具，将工具 ZIP 解压后的 merge_v7.py、v7_split_manifest.json 与全部 partNNN.zip 放在同一文件夹。
2. 使用 Python 3 运行 `python merge_v7.py`。工具逐卷校验大小与 SHA-256，合并后再次核对整包 SHA-256 和 ZIP CRC。分卷是数据分段，不能逐卷当作独立补丁覆盖。
3. 解压生成的 diandian_male_pose_v7.zip。保留其中 apply_update.py、manifest.json 与 files 文件夹的相对位置。
4. 先备份自己的工程，确保仓库所需 Git LFS 大文件已下载。运行 `python apply_update.py "你的diandian工程目录"`，先只检查，不写入。
5. 检查通过后运行 `python apply_update.py "你的diandian工程目录" --apply`。安装器接受已验证 main 或 V6 文件状态；发现未知修改、错误路径或缺失基础大文件时，整批停止，不覆盖。
6. 原文件备份保留于工程的 work/weapon-v7-backups/<时间>。如需回滚，执行安装输出的 `--rollback` 命令。若安装后又修改了相关文件，回滚会先停止，避免抹掉新改动。
7. 重复安装同一包不会重复修改已经正确的文件。网页入口与新增动作包使用 V7 版本号，需刷新页面让新资源加载。

不要直接把 files 文件夹改名为工程，也不要只拿新 GLB 而遗漏配套枪挂点配置、运行时约束和其他 V6 依赖。完整文件清单及每个文件的哈希见 manifest.json。

## 网页与引擎资源

- 网页入口：web/motion-labs/linxu-motion-lab/ 与 web/motion-labs/resistance-motion-lab/。
- 网页运行时的新四枪 28 动作包：各角色目录中的 weapon_update_v7.glb，搭配本包 weapon_attachment.json 与 weapon-attachment.js 使用。
- assets/characters/weapon_update_v7/<角色>/motions.glb 与 equipped_motions.glb：与网页一致的新四枪 28 动作。
- equipped_all_motions.glb：九把枪共 59 个装备动作，含已应用的旧枪程序修正；不是空手动作替代包。
- equipped_all_weapon_transforms.json：每个装备动作对应的右手局部枪位、枪旋转和泵柄位移。引擎中需与同名 Equipped_<武器>_<动作> 同步采样。
- 使用全 59 动作烘焙包时，不可再叠加网页的旧枪 IK/手指约束，否则会重复施加修正。需要匹配原角色骨架，保留原节点平移、骨长和比例。
- 烘焙频率：静态/待机/瞄准 60Hz，移动/换弹 120Hz，射击/拉泵 240Hz；动作原时长不变。
