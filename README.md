# 点点滴滴 · 刺瑰行动

Unity 6 第三人称叙事射击框架，基于《点点滴滴》剧情方案 2.1。当前交付为可继续开发的源码工程：角色、战斗、点点协作、任务、菜单和存档已经接在同一条流程中。

## 打开

1. 在 Unity Hub 中选择“添加项目”，选中本目录。
2. 使用 **Unity 6000.0.62f1（Unity 6.0 LTS）** 打开，等待 Input System 1.11.2 与资源导入。
3. 双击 `Assets/Game/Scenes/Boot.unity`，点击 Play。也可使用菜单 **点点滴滴 → 运行框架原型**。
4. 在主菜单选择“开始新的旅程”或“章节试演”。

渲染使用 Unity 内置 3D 管线；输入已设置为 Input System。Input System 1.11.2 已作为本地包随工程提供，来源为 Unity 官方仓库的同版本源码。启动场景由组合根建立角色、几何关卡和相机，无需手动拖引用。第一次导入后 Unity 会补齐其余默认工程设置。

## 当前内容

- 林叙：肩后视角、移动、冲刺、蹲行、跳跃、瞄准、生命与失败重试。
- 枪械：六类共 **18 把**；主副两槽、各自弹药、射速、换弹、散布、霰弹多弹丸、榴弹飞行与范围爆炸、弹迹和枪模后坐。
- 敌机：巡逻、观察、重载、中继四类行为配置；视线射击、开火预告、协作压制、光学弱点。
- 点点：随行、单键上下文协作、短时压制，以及校准、默契、受伤、职责反转、接入、遗忘、沉默的剧情阶段。
- 剧情：序章、第一至第十章、尾声，**12 章 / 53 个顺序任务目标**，包含章前章后对白与目标交互字幕。
- 界面：中文主菜单、章节选择、HUD、对白、暂停、军械库、失败、章节完成、尾声。
- 场景：城市维修通道、掩体、控制台、目标信标、一次性补给箱及营地物件。
- 存档：目标推进自动保存；继续或失败重试从当前任务段开始，恢复章节、任务计数、武器配置与同伴阶段。该段生命、弹药和敌人重新建立。

12 章目前复用一套通道原型，展示章节与系统的接入方式。人物、枪模和场景使用几何占位，声音是程序生成的临时枪声。原方案 5—6 小时完整流程、正式美术、角色动作、配音、无人机操控与完整 Boss 演出尚未制作。

## 操作

| 操作 | 输入 |
| --- | --- |
| 移动 / 观察 | WASD / 鼠标 |
| 瞄准 / 射击 | 鼠标右键 / 左键 |
| 冲刺 / 蹲行 / 跳跃 | Shift / 左 Ctrl / 空格 |
| 换弹 / 主副武器 | R / 1、2 |
| 场景交互、补给箱 | E，靠近目标 |
| 点点协作、压制 | Q，协作任务需靠近信标 |
| 军械库 / 暂停 | Tab / Esc |
| 保存当前任务段 | F5 |

青色信标指示交互与路线目标，橙色信标指示交火区域。掩体直接参与物理遮挡；敌机光学球为弱点。补给箱位于通道左侧，靠近后按 E 补充生命与弹药。军械库在原型中随时可用，便于体验全部武器。

## 继续开发

| 位置 | 职责 |
| --- | --- |
| `Assets/Game/Scripts/Core` | 入口、游戏状态、系统组装、输入与章节切换 |
| `Assets/Game/Scripts/Actors` | 玩家、相机、点点、敌机 |
| `Assets/Game/Scripts/Combat` | 生命、弱点、武器行为与榴弹 |
| `Assets/Game/Scripts/Narrative` | 章节、任务推进、JSON 检查点 |
| `Assets/Game/Scripts/World` | 原型场景生成、目标与补给 |
| `Assets/Game/Scripts/Presentation` | 中文 HUD 和菜单 |
| `Assets/Game/Resources/Weapons` | 18 个可在 Inspector 中调整的武器资产 |
| `Assets/Game/Resources/Story` | 12 个章节资产 |

新增枪械时创建 `WeaponDefinition`，使用唯一 Id，放入 `Resources/Weapons`。现有六类共享同一套射击逻辑。新章节使用 `ChapterDefinition`：Order 决定顺序，任务按数组顺序推进，Kind 决定到达、交互、协作或击杀；击杀任务 Id 固定为 `hostile`。正式关卡可保留任务上报接口，替换 `WorldBuilder` 的几何构造。

本工程采用直接组件引用和明确初始化，不引入额外 DI、全局事件总线或逐枪继承框架。存档位于 `Application.persistentDataPath/checkpoint.json`。
