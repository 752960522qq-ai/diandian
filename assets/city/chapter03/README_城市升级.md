# city.glb 城市细节替换

已用 Blender 4.3.2 在上传的 city.glb 上替换 126 处可独立识别的楼体单元，采用 hero_13 城市库中的 10 款建筑。道路、弯道、路口、高架与坡道沿用原场景；建筑按原楼体中心、地脚高度及包络主轴放置，平面包络向内留约 2% 余量，高度沿用原目标楼体。

## 文件

- `city_hero13_detail.blend`：可编辑 Blender 工程，贴图打包；替换建筑按 R001～R126 分组，同款模型共享网格；每组编辑原点位于自身楼底，主轴在根节点上保留。
- `city_hero13_detail.glb`：静态场景，贴图内嵌，可以导入 Godot。
- `city_before_overview.png` / `city_after_overview.png`：同视角修改前后总览。
- `city_before_top.png` / `city_after_top.png`：同朝向俯视图，便于对照路网。
- `city_detail_corner.png` / `city_detail_street.png`：实际 Blender 渲染的近景。
- `replacement_manifest.json`：每处原楼体、位置、主轴、包络尺寸及替换素材对应表。

场景实例展开约 494.6 万三角面；同款建筑保留共享网格。GLB 内有 305 张内嵌图像，无外部贴图路径；Blender 工程中使用的 310 张图像均已打包。它是高细节源场景，运行时分块和 LOD 可在接入关卡时继续制作。

素材来自 `hero_13/delivery/city_updates/v19_20261030/building_bank` 中的亚洲建筑和办公楼，以及 `v16_20261029/sources` 中的两款公寓。v19 单栋由其现有分卷恢复；原始来源和对应关系见该版本 `annotations/building_asset_catalog.csv`、`building_bank/manifest.json`。沿用用户提供素材的原授权范围，本次未修改 hero_13 源文件。

原场景里不适合独立替换的超薄背景立面、远景片和特殊结构继续保留，避免强行拼入完整楼房后影响道路关系。这里的 126 指替换单元数，不是对整城建筑总数的重新统计。上传模型的原始坐标、缩放和原点保持；接入角色控制器前应统一确认项目单位。

## 推荐章节：第三章《借你一会儿》

推荐作为第三章“补给线街区”的外部推进段。完整剧情方案第 3.2 节把商住与货运街区用于补给线和重载工程机战斗，第三章也需要观察通路、清除观察器、两拍协作及任务后的短暂相处；这张狭长旧街、横向道路与高架高差的组合最贴合这些需求。

1. 入端街口：设置安全观察点，让玩家先观察两条推进方向。
2. 中段旧街与横路：沿原道路推进，利用拐角绕侧，处理观察无人机与守卫。
3. 高架相邻街段：加入点点短时牵制、林叙击破弱点或插入支撑件的协作目标。
4. 远端弯街与横向出口：打通补给出口，在临时安全处接半块饼与拍照互动。

无人机点、车辆、敌人、支撑件和剧情触发器是后续关卡内容，不在本静态模型中。重载工程机的完整 Boss 场地适合另接一块装卸场，不必为了容纳它改动当前楼位和路网。

本次交付是模型与材质升级，未烘焙游戏碰撞、导航或角色交互。场景仍包含原素材的部分开放边缘，不能将所有楼都当作可进入建筑使用。
