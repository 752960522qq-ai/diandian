# 第三章城市 · 未标记素材版

本版遵循用户已确认的规则：hero_13 中带 `Sxx-Bxx` 来源编号的模型禁用，只从没有这类标记的来源文件选取素材。

旧版8款带编号素材的123处引用已全部替换。本场景从原始上传的 `city.glb` 重新构建，未加载旧版替换工程，因此旧模型及其贴图不会留在隐藏物体或未使用数据中。10款未标记候选中，实际落位8款，仍有126处楼体替换。

## 模型与布局

- `city_hero13_detail.glb`：当前静态场景，108张内嵌图像，无外部贴图链接，节点及材质元数据未发现禁用编号。
- `city_hero13_detail.blend`：可编辑工程；110张图像打包，楼体按R001～R126分组，编辑原点在楼底。
- `replacement_manifest.json`：原楼体位置、地脚、包络、主轴及新素材对应关系。
- `asset_selection.json`：当前来源文件、SHA256、标记筛选结果、实例数量及旧版排除名单。
- `layout_summary.json`：布局对照摘要。

原道路、弯道、路口、高架、坡道和保留物件沿用；2276个保留网格与原始场景对照一致，可见原网格的变换误差为0。新楼体维持原包络中心、地脚高度和主轴，平面向内留约2%余量。原城市坐标、原点和整体缩放不变。

场景实例展开约302.1万三角面，同款楼共享网格。仅替换可独立识别的楼体；原有超薄背景和特殊结构继续保留。

## 建议章节

适合作为第三章《借你一会儿》的补给线街区段：街口观察通路 → 旧街绕侧推进 → 高架旁与点点协作 → 补给出口。完整工程机Boss场地可接在后续装卸场，当前街区无需改动楼位与路网。

当前交付为静态模型，未新增敌人、无人机观察点、协作装置或剧情触发器，也未配置游戏碰撞和导航。
