# 点点经典形象 · 面部绑定与动作适配

本版保留上传模型的经典外形、网格、UV、材质与原有65根身体骨骼。移植 hero_13 夏晴R23的246根面部骨骼，按点点脸部位置适配，另加1根下颌控制骨 `DD_Jaw_CTRL`，合计312根骨骼。重绘19,887个顶点的头脸及头颈过渡权重，处理下巴在大幅动作中被身体牵动的问题。

原网格仍为107,452个顶点、50,206个三角面；顶点位置、UV及原身体骨骼的静止姿态与上传版本一致。

## 动作

| 动作 | 时长 | 来源与用途 |

| `Idle` 待机 | 8.333秒 | 夏晴R23动作，适配点点身体比例 |
| `Walk` 走路 | 1.167秒 | 夏晴R23动作，适配点点身体比例 |

动作按30fps烘焙为原地循环。走路另做支持脚高度适配，跑步保留腾空阶段。修复前对照模型使用同一套身体动作，保留原始权重，便于在同一时刻比较下巴表现。

## 下巴对照结果

在 `HeadStress` 第0—120帧、每10帧采样一次，对选定下巴区的4,676个顶点共采样60,788次。下巴区取原始Blender世界坐标 `0.875≤z≤0.906、y<0.07、|x|<0.05`（米），排除Icosphere；以顶点随头骨刚性运动的位置为参考。该诊断中，最大跟随偏移从约31毫米降至0.000182毫米，低于0.001毫米。这项数值对应上述区域与扭转采样。

## 交付与使用

- `diandian_classic_fixed.blend`：可编辑的骨架、权重及动作工程。
- `diandian_classic_fixed.glb`：修复后的模型与四套动作，贴图内嵌。

- `rig_info.json`及附带来源、绑定与检查清单：骨骼、动作和适配记录。

面部骨架与下颌微动可用于继续制作表情；本次没有制作完整的语音口型或表情动画库。
