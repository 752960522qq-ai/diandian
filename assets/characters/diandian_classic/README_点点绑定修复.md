# 点点经典形象 · 原动作适配与大臂调整

本版使用本次上传的 `girl_Idle.fbx` 与 `girl Walk.fbx` 重新适配待机和走路，全部65根身体骨骼按世界方向与掌面校准，保留源动作的肩胯、脊柱、手臂和重心侧摆。跑步沿用夏晴R23动作。

- 待机：两只脚分别做脚掌修平与腿部IK，保留原有朝向和自然重心变化，前后脚都落地。
- 走路：保留约29.7毫米左右侧摆与27.2毫米前后重心变化；骨盆上下起伏控制在16毫米，通过支撑腿适配地面。
- 两侧大臂：肩点固定，肩到肘长度从约156.08毫米缩为148.27毫米，即原来的95%。小臂、手掌和手指整体随肘平移，各自段长与粗细保持。
- 头脸：保留246根夏晴面部骨与下颌控制骨，继续使用自然头颈跟随；头脸网格和蒙皮权重未改。

模型共312根骨骼，107,452个顶点、50,206个三角面。大臂区域的顶点只沿长度方向调整，UV与全部蒙皮权重保持。

## 文件

- `diandian_classic_fixed.blend`：可编辑骨架、权重和动作工程。
- `diandian_classic_fixed.glb`：模型与Idle、Walk、Run、HeadStress四段动作，30fps，贴图内嵌。
- `diandian_classic_before.glb`：同样的大臂长度与当前动作，使用上传经典模型的原始蒙皮权重，供绑定对照。
- `source_animations/`：本次两份原始FBX。
- `upper_arm_report.json`、`adaptation_report.json`、`final_audit.json`：尺寸、来源、适配及接地记录。
- `idle_boots_preview.png`：待机脚部近景；其余预览为本版页面与动作。
