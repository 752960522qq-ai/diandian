# QBU-10（R44）

使用用户上传 `QBU-10.glb`；原件保留在 `source/qbu10_source.glb`。按用户最终指定的 **1.15 m 全长**等比规范，+Y 向上、−Z 为枪口朝向。保留原几何、贴图和展开脚架，规范变换位于单独父节点，详情见 `qbu10_report.json`。

两个角色网站使用原有普通步枪六种动作：待机、行走、跑步、瞄准、射击、换弹。双手握点按实际模型表面调整，左手支撑护木后段、位于弹匣前方；瞄准和射击抵肩。两站 `assets/weapon_attachment.json` 保存各角色适配参数，Godot 现有步枪预览也登记此枪。

执行 `node tools/gltf/prepare_qbu10_r44.mjs` 可重新生成规范模型和报告。此脚本只规范视觉资产，不改变武器伤害、射程等玩法数值。
