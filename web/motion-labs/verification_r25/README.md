# 97式待机双臂外展

仅调整点点97式的RifleIdle挂点参数。左手改在护木前段承托，接触点仍位于实际泵柄范围；微调腕到掌偏移与掌角，让左肘从身体内侧转到前侧，并略向外展开。右肘增加适度外展；枪体位置和其他动作保持。前臂扭转参考设为90°，避开此掌角在旧参考下出现的分支跳变。

完整8.5667秒待机以240Hz采样2057帧：左肘相对肩部外侧方向的投影从−97.94至−73.43mm变为+12.03至+38.58mm；右肘为+118.10至+126.07mm。最大腕弯左27.67°、右6.27°，最大相邻骨骼旋转0.329°，最大手部接触残差0.000000173m；切换动作后返回待机一致，其他动作与武器对照无变化。

正面、侧面、俯视的实际蒙皮检查通过。握指细节沿用上一修复，极近景可能仍有轻微指尖与枪体表面穿插。此次不修改GLB或Godot组件。通过Sites自身源仓库更新线上；GitHub未推送。
