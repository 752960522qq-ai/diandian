# R44：源 GLB 手掌、抵肩机枪、独立坦克站与 QBU-10

本轮交付：

- 点点当前高精度源模型 `assets/characters/diandian_classic/diandian_classic_fixed.glb`、网页当前模型与对照模型都内嵌 90% 手掌缩放。写入左右手节点和模型自身所有动作的手部缩放轨道；原几何、贴图、蒙皮逆绑定数据保持。网页不再额外乘 0.9，接触点计算仍使用实际手掌大小。保留原预览定位基准，避免缩手引起包围盒居中偏移。
- 两名角色的 QJZ89 待机、瞄准改为枪托抵住右肩，右手握把、左手放枪托上方。枪口朝向固定，位置随肩部呼吸移动；不提供携行，支架仍悬空。枪身保持 1640 mm。
- 59D 保持总长 9200 mm，独立为 `type59d-motion-lab` 站点。两个角色站移除各自 23,366,876 字节的坦克 GLB 和坦克预览模块，改为普通跳转链接。R43 原本按需加载坦克，因此这里记录资源拆分，不宣称首屏网络流量原先包含坦克。
- QBU-10 按用户最终指定的 **1150 mm** 等比规范；保留上传材质和展开脚架。使用原有普通步枪待机、行走、跑步、瞄准、射击、换弹动作，并校准右握把、护木后缘支撑点和抵肩点。

验证结果：

- 源模型脱离网页独立播放：三个 GLB 的 105 个姿势，手部长度比为 0.9，最大比例误差约 2.21e-7。
- 两人各 1068 个新持枪姿势：最大握点误差小于 0.001 mm；待机/瞄准机枪及 QBU-10 瞄准/射击的枪托抵肩检查通过。切换复位通过。
- 原 11 种武器各 342 个姿势与已发布 R43 源码和模型对照：点点最大差 0，知更骨骼数值最大差 1.33e-6。
- 32 个姿势检查：QJZ89 三脚架与腿部、QBU-10 脚架与躯干/手臂/腿部三角面未检出相交。排除有意接触枪身的手部；这是有限采样，不是全部帧、全部衣物的穷尽碰撞证明。
- 实际浏览器验证两个角色站和独立坦克站，检查按钮、六种 QBU-10 动作、双手机枪姿势、原 PF89/手枪入口、390 px 布局、后坐单次播放/重播与页面错误。角色站没有坦克请求，坦克站只加载一个坦克 GLB。另验证点点保留原定位基准。
- Godot 两套角色预览的手掌、抵肩机枪、QBU-10 和坦克检查通过。Blender 保存的两套抵肩场景各检查 10 个姿势，枪托与肩部目标最大误差小于 0.001 mm。
