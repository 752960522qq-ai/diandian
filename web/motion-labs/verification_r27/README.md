# 97式：左臂前伸与枪身前斜

在修订26保留的外展姿态上，仅把点点97式待机、走路的枪体挂点旋转绕枪身局部Y轴向前偏转15°。原左右握点、左掌朝向相对枪体、肘部外展权重及枪体平移参数保持，由双臂握持约束带动左臂前伸。没有把姿态改回修订25的前移收肘版本。

完整待机2057帧、行走313帧，以240Hz检查。相对修订26，左肘前移69.6–80.4mm，左腕前移76.2–89.6mm；按人物身体方向计算的枪口水平朝前变化约14.47–14.85°。左肘仍保持176.9–192.1mm的外展投影。最大腕弯左19.21°、右27.02°，最大相邻骨骼步长0.199°，手部接触残差小于0.000000173m。

身体、腿部骨骼比较差异为0，切换动作并返回同一时刻差异为0。待机/行走的俯视、正面、侧面实际蒙皮图检通过；重新载入确认新参数生效，未发生脚本错误。配置差异仅含两个动作的quaternion_xyzw字段，其他武器及动作参数不变。
