# R46 男性基础动作替换与姿态修复

已部署到[抵抗军动作站](https://resistance-motion-lab.expert-eagle-6942.chatgpt.site)，保留原站点地址与访问范围。

用户要求以两份新 FBX 替换抵抗军待机/行走，并自查全部姿态扭曲及握枪问题，重点 QBU85。

## 原因与修复

R45 逐骨只匹配单个方向，骨轴旋转缺少完整参照；躯干、锁骨及指骨也受另一角色的静止姿态与握持参数影响。本轮改用完整解剖坐标架，保留抵抗军自己的中立形态，并平滑限制瞄准时过度的头颈偏转。

原握持锚点不代表真实皮肤接触，QBU85 左支撑点甚至偏在狭窄护木外侧。新校准从实际变形掌面和枪械三角面测量接触位置，并调整 QBU85 携枪角度及 QBU85、QCQ171、56-1 的装备包避让。

## 验证

- 上传来源：Idle 8.333 s、Walk 1.033 s，均由新 FBX 通过 Blender 采样，原件 SHA256 与动作来源完整归档。
- 资产检查：1010 姿态，33 段动作/角色，骨长、轨道绑定和变形坐标正常。
- 头颈：1952 个采样满足平滑限幅；蒙皮回归覆盖 4026 帧，保留已修好的背心异常顶点。
- `attachment-validation.json`：两人共 5246 帧，五种枪的指定握持点误差小于 3 mm；反复切换无累计姿态偏移。
- `surface-validation.json`：对变形后的实际掌面进行射线检查，并检查低携枪时前臂与躯干/装备包前表面的间距。该检查独立于握持锚点误差。
- `browser-validation.json`：86 个角色/装备/动作组合及手机布局、播放、时间轴、速度、骨骼和按需加载。
- `final-smoke.json`：最后的 QBU85、QCQ171、56-1 行走与男性 Walk 专项复查。
