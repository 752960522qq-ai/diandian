# 97式防暴枪左手握持修复

基于点点线上第32版源码修复，保留其腰部模型与已有适配。左手掌心移到护木下方并校准腕到掌偏移，待机、行走、跑步、瞄准、开火采用斜向承托，拉泵另设角度；肘部以掌轴与身体向外方向共同引导。左指采用一致的局部关节姿态，避免AR和霰弹枪混合动作切换时手指张开。拇指各关节调整分别限制在40°/45°/35°以内。上臂扭转分摊为0，前臂参考分支为−90°，支持直接时间跳转。

最终运行时六类持枪动作按240Hz共采样3521帧；待机腕弯4.83–6.13°，所有持枪动作最大23.90°，手臂相邻旋转步长小于2.8°。66项其他武器姿态、97式右手与枪体姿态在1e-12容差内不变。时间轴反向跳转、切换武器回托和泵柄归零通过。结果详见type97-validation.json。

侧面、上方和全身实际蒙皮图检未见严重翻腕；极近景仍可能看到少量指尖与护木表面穿插。网页运行时适配未移植至Godot。
