# R43：QJZ89 与 59D 接入验证

两人动作站增加 QJZ89 固定机枪，新增 59D 无人坦克独立预览。QJZ89 仅站立待机、瞄准，右手握把、左手置于枪托上方；机枪悬空。59D 无驾驶员，保留原六段机械动画。此轮未加入关卡战斗 AI。

指定尺寸按实际变换后的模型测量：QJZ89 枪身 1640 mm，59D 静止总长（含炮管）9200 mm。原上传文件另行保存；GLB 的原始几何、贴图、蒙皮与动画二进制数据保留，规范轴向与比例通过节点变换实现。QJZ89 后支架额外向外展开，避让大腿。

验证范围：

- `validate_emplacements_r43.mjs`：实际尺寸、上传二进制数据保留、两人各 702 个站立待机/瞄准姿势的有限数值与双手握点、枪位不漂移、切换复位和烘焙一致性。59D 五个预览动作各采样 61 帧，并验证切换复位。
- `regression_emplacements_r43.mjs`：以两个已发布 R42 源码目录为基线，两人各 342 个姿势、原有 11 种武器的骨骼和武器状态对照，最大差为 0；原武器配置保持。
- `browser_emplacements_r43.mjs`：真实浏览器按钮、机枪待机/瞄准和双手特写、坦克五种动作、后坐单次播放与重播、人物/坦克往返恢复、快速切换、390 px 布局、PF89 与原手枪射击入口以及页面错误检查。
- `validate_emplacements_r43.gd`：两套实际 Godot 预览场景，烘焙动作映射、62 个握持姿势、坦克动作和可见性，以及返回原手枪动作。
- `validate_uploaded_motions.gd`：原八段动作、骨骼映射、40 个姿势和武器可见性回归。
- Blender 4.3.2：两套带固定机枪的可编辑人物场景及包含六段原动画的 59D 场景保存成功。

`validate_emplacement_clearance.mjs` 使用变形后的下肢三角网格和三根支架网格。两人各检查待机与瞄准共四个时刻，修订后未检出三角面相交；不代表所有时刻、所有衣物表面的穷尽碰撞证明。采样记录见 `clearance.json`。

详细结果见 `runtime.json`、`regression.json`、`browser.json`、Godot/Blender 日志和截图；最终文件 SHA-256 见 `manifest.json`。网站发布结果另记于 `deployments.json`，GitHub 工作区保持未推送。
