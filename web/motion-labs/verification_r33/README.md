# 修订33：握持与手臂避让

本轮按用户截图处理四项问题，保留 r31、r32 其他修复。仅修改网页运行时与握持参数，不改角色模型、源动画或 Godot 组件。

- 两人汉阳造行走：左手沿护木后移 45/55 mm（枪体局部坐标），左肘外向引导 0.4，上臂扭转分摊降至 0.25。保留 r32 右手和枪体；在截图 0.32 秒附近从接近伸直改为约 134–137° 的自然曲肘。
- 两人 QCQ171：以中指掌指关节为稳定几何参照，重新落位右掌与环握指节，覆盖待机、行走、跑步、瞄准、开火。瞄准/开火的枪托接触点改到右肩窝：下移参数 −25 mm、前向 50 mm、内向点点 35 mm/知更 40 mm。左掌与护木的局部相对关系保持 r32。
- 两人 QBU85：待机/行走/跑步分别增加 22/16/25° 枪托上扬倾角，并联合修正右腕朝向。新增可选的 `right_elbow_hint_weapon_m`，使肘部弯曲平面随枪体保持在枪托下方；解析双骨 IK 保留骨长。行走左手沿护木后移 25 mm 避免接近伸直，跑步增加少量左肘掌轴引导。瞄准、开火与换弹保持。
- 知更97式瞄准待机：重新校准左掌方向、护木接触点、握指和肘部引导；保留枪体、右手、躯干、腿部及97式开火/拉泵。待机、行走、跑步也保持。

`assets/weapons/character_attachment_v33.json` 为共享参数归档。两站 `assets/weapon_attachment.json` 仅合入对应字段，保留原资源路径和站点设置。HTML、app 和握持模块缓存版本更新到 r33。

- 336 项 r32 对照通过：限定修改范围外的骨骼姿态、枪体矩阵一致。包含其他武器、换弹和97式射击/拉泵。
- 19 项暂停重复求解、切枪再恢复检查通过；未出现累计姿态漂移。
- 390 px 手机页面加载、播放和布局检查通过，两站无 JavaScript 页面错误。
- QBU85 全循环枪托间隙采样：使用枪托实际顶点（枪体 Z > 0.435 m）与右前臂锥形胶囊代理（肘端半径 46 mm、腕端 25 mm）检查。修改后的待机/行走/跑步最小间隙分别为点点 31.83/40.60/24.32 mm、知更 9.97/19.23/10.78 mm。此为几何代理采样，配合截图检查，不是全蒙皮三角形连续碰撞证明。
