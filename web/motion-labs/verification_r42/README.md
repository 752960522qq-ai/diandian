# R42 验证记录

针对点点、知更的倒退行走与手枪射击修订。未接入手枪 locomotion 压缩包；其余六段 R41 新增动作的轨道时间和值逐项对照保持完全一致。倒退行走除左右上臂旋转外，其他 64 条轨道保持完全一致。

验证工具：

- `tools/qa/validate_motion_r42.mjs`：两人各 59 帧覆盖完整倒退循环。按蒙皮权重选取实际手部和下肢三角网格，采样手部顶点的有符号间隙；30 个时刻进一步检测手腿三角面相交。检查循环首尾。两种手枪各以 120 Hz 采样 141 帧，核对双手接触、抬手幅度、枪体角度连续性、原瞄准起止姿势和动作切换复位。
- `tools/qa/browser_motion_r42.mjs`：Chromium 实际按钮操作、倒退多阶段正面/侧面图、两种手枪的瞄准/上扬/回落、单次播放与重新播放、390 px 布局和浏览器报错检查。
- `tools/qa/validate_uploaded_motions.gd`：两套实际 Godot 预览场景，八段动作的骨骼映射、循环设置、武器显示和 40 个姿势的有限数值检查。
- `tools/blender/save_motion_r42.py`：Blender 4.3.2 导入最终动作，核对八个动作、有限关键帧数值，保存可编辑人物文件。

结果详见 `runtime.json`、`browser.json`、`godot.log`、`blender.log`；`manifest.json` 保存最终资产与网页文件散列。检查覆盖上述离散采样及截图视角，不代表所有连续时刻和所有衣物表面的穷尽碰撞证明。

最终运行时检查通过：两人各 59 帧倒退采样没有手部入腿样本，三角面检查没有相交。点点最小手腿间隙 10.17 mm，知更 21.07 mm，循环首尾误差小于 1e-5。两种手枪的左手接触误差分别不超过点点 1.48 mm、知更 1.13 mm；右手误差接近浮点精度。射击起止与原瞄准对应，扳机手指迭代约束放大的最大骨骼四元数分量差 3.85e-5，切换复位检查通过。
