# 点点、知更 M870 跑步肩部定点复核

原 M97 与最终 M870 D 在同一相位、同一机位进行实际蒙皮对照。点点检查20%和70%相位，知更检查15%和90%相位，各覆盖左右肩前后视，共32张渲染，汇总为本目录6张对照图。

这几个高扭转或相反相位未观察到林叙式明显肩根夹细。原／新肩袖轮廓接近，因此没有把三位男角色的修正机械套用到两女，保留其原动作与最终D绑定。

此结论只覆盖上述肩部定点，不代表两女全部动作、所有连续帧或隐蔽穿插均已排除。图像来自实际模型与运行时骨架的离线渲染，不是浏览器像素验收。

图中主要对照为左侧原M97、右侧最终M870 D。个别文件名的left/front标明实际前方视角；三行联系表补充两侧后方和前方。角色解剖学左侧对应模型世界+X。
