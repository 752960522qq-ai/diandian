# 林叙 V4 修改与验收

基于 `752960522qq-ai/diandian` 的 `main`：`f0efeaec1f45457aa97c1705e1f7b006a1447231`。此前 V3 修改包的48个文件均已与该提交匹配，无需重复安装 V3。未提交、推送或部署。

## 完成的修改

- **短颈是真实模型修改。** Neck→Head 骨段缩短18%，原网页比例下约16.52毫米。只对颈部做平滑几何过渡，头、脸和头发整体下移，不缩放脸或身体；同步更新头部后代逆绑定。原始上传模型保留。
- **按林叙自己的手型重新拟合。** 检查了蒙皮与骨长，去掉直接照搬另一角色的过度指节弯曲，按每支枪的实际表面调整双手。最终非拇指PIP最大约98.44°、DIP最大约70.00°，没有整体重刷手指权重。非射击时食指离开扳机，射击使用单独的受限姿态。
- **重新校准整臂与枪托。** 分别修正五枪的持枪位置、肘部方向和扭转，瞄准抵肩时保留真实肩面附近的枪托关系，未采用把枪移远、枪托悬空的失败方案。
- **修复不兼容的动作上身层。** 97式射击、拉泵、持枪奔跑重新校准上身姿态；QBZ95、56式、QCQ171换弹使用稳定的右持枪/躯干层。Hips、Spine及腿部仍使用各自动作；97式泵件行程保留。部分旧上身/右腕大幅摆枪被有意替换，不是逐骨保留原装备动画。
- **释放的左手另做避让。** 换弹时不锁住左手握枪，针对实际手、前臂、上臂蒙皮生成侧向避让。最大侧移约20.91厘米；这是避免穿枪的通用手势，**不是重新制作了真实拆装弹匣动画**。
- 重新烘焙31段装备动作和枪体/泵件变换。V3基础动作文件、无武器肩部调整、原始模型及原枪械网格不改。

- **31段装备动作的3070个导出帧全部检查实际蒙皮。** 普通动作30Hz，射击及拉泵240Hz；采用与烘焙一致的采样时刻。对39,086个按手、上身、头颈主导蒙皮权重超过35%筛选的顶点，测量真实枪网格的最近面和14方向射线一致性，至少12方向一致且最近面朝内才计入强穿入。

## 仍有的限制

1. 仍有上表所列的**毫米级嵌入**，没有宣称全模型全时间零穿模。射线方法面对开放、非流形或相互重叠的枪械壳面只是诊断；逐顶点检查还可能漏掉三角形内部交叉，未证明帧间连续运动或手指之间绝无自交。
2. 部分右腕的几何夹角仍较大，尤其97式低抱枪。它不是手指反折，但并非每个手腕都达到最佳美术造型。瞄准姿态也未宣称精确完成瞄孔/眼线标定。
3. 换弹保留通用自由手手势，并非逐枪的弹匣拆装流程。部分躯干姿态被修正后，自由左手的世界轨迹也发生变化；其局部释放动作与避让都已写入最终烘焙。
4. Chromium在页面加载前因环境的socket限制启动失败，**浏览器UI、手机端交互和实时WebGL未完成实测**。Node数值验证与离线GLB渲染不能替代这些测试。
5. 未做Godot人物/武器控制器接入、游戏内播放、Android性能或线上部署。原有不涉及本次修改的场景也未做全项目验收。
