# V7 男性旧枪动作复核

本目录覆盖林叙、军装抵抗军和背心抵抗军的 QCQ171、97式、QBU85、56-1、QBZ95。图片为真实运行时骨骼与原贴图网格的离散相位渲染，不是绘制示意，也不是所有时刻及角度均无穿插的证明。

- `idle/`：15组人物×武器，各显示完整待机周期9个采样相位；上行V6，下行V7。
- `key_shots/`：对应用户标记位置附近的5组林叙前后近景。拍摄角度是便于比较的近似视角，帧为相邻采样，不是复用手机截图原像素。
- `actions/`：持枪行走、瞄准、射击、97拉泵的5组代表性前后对照，分别显示起点、中点和终点。
- `metrics/`：实际运行时手指角限制、限定修改范围的数值复验，以及源文件指纹。

## 修改与残留

林叙五枪存在同一拇指根参考姿态过度翻转，导致手背与腕部蒙皮出现黑缝。V7向原有自然根姿态部分回退：QBU85为60%，其余为50%，没有改动源动画时长。三角色分别按枪支和动作修正经过扫描确认的手指末节过折，不将全部手指拉直。林叙QBZ95待机右肘下移约1.3cm，枪体旋转6°，与原有持枪姿态保持接近。QCQ171手机图中右袖/后托在截屏时刻及另外4个采样相位的右臂与枪三角面检测为0交叉，主要为遮挡近邻；不为它无谓转枪。

97式待机的枪托与前臂问题按角色分别处理。林叙保留原肘角，小幅协调枪向、右掌及食指/小指：17个采样相位的右臂（含腕区）未检出枪体表面交叉，左臂5个相位未检出。军装抵抗军调整右臂、手掌及食指参考姿态，17个相位距腕6cm以外的前臂/枪体未检出交叉；腕部握持区域仍存在接触或相交，不能称整只手零穿插。背心抵抗军原仅有局部轻微接触，保留原姿，避免引入新的手指问题。以上为离散相位检测，不是连续时间或全身碰撞证明。97的走、跑、瞄、射、换弹与拉泵各抽查了多个相位，其原有接触没有因本次待机配置改动而改变；该检查不声称旧有动作所有接触都已消除。

QBZ95修正后，右臂17个采样相位、左臂5个采样相位未检出枪体表面交叉。林叙QBU85与56-1的拇指末节和指尖在7个采样相位未检出枪面交叉，近端包握区域仍有接触或相交，不能称整只手零穿插。

手指限幅共98项，61相位计5,978个样本通过；几何手指角度的数值结果不能代替最终目视。465组动作/相位检查中，除明确的林叙QBZ95待机、林叙和军装97待机枪与双臂调整，以及指定手指外，其他骨骼姿态与枪体位置未发生实质变化；动作时长未变。界面动作切换仍是原有直接重置，不代表新增平滑过渡。

## 重现

需要Node.js、Three.js 0.180、Blender及Python Pillow，保留项目原有工具。`tools/weapon_v7_legacy/capture.mjs` 从生产 `prepareRig().pose()` 采样并输出实际骨骼与枪体，`render.py` 在导入GLB前设置240fps并渲染；`package_evidence.py` 汇总图像。`verify_fingers.mjs` 对配置限幅做多相位验证（设置 `PHASES=61`）；`verify_hawk_switches.mjs` 验证97各动作反复切回待机的状态稳定；`verify_scope.mjs` 需要另行指定可读取的冻结V6目录以作前后对照。脚本与数据的用途和限制见各文件注释。使用项目最终烘焙版本时，应在导出之后重新验证其回读骨骼与武器轨迹。
