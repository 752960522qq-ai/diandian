# 高位持筒校准说明

两角色使用PF89局部左掌接触点 `[-0.027,+0.055,+0.200]` 米。待机、行走、跑步不再套用下托手腕方向，而直接保留相应里昂上半身重定向动作的左手世界朝向。肘部以源姿态为主，外展修正权重0.3；保留现有手腕扭转分摊。

选择后向+0.20米，而不是+0.24米，是为了减少相对源左肘的位移。两者均能形成高位持法并通过候选交叉检查，但+0.20米与原姿态更接近，实际模型目视也更自然。握点不能直接照抄源腕坐标，因为PF89原点、握把位置和两角色体型均不同。

本版最终配置的可复现结果在 `carry-source.json` 与 `carry-clearance.json`：每人1268帧120Hz，左腕始终高右腕至少15.34/15.21厘米；源左手方向误差小于0.05°，动作内最大局部步长约0.68/0.71°。两种交叉检测均为0。

跑步首尾左前臂仍有约3.46°/3.19°循环缝，因此不声称完全无缝。检测采用左臂中心线与实际蒙皮躯干表面、实际筒体三角面与头/躯干表面，不能作为全部衣物和皮肤在任意时刻无接触的穷尽证明。
