# 林叙旧长枪奔跑多角度复核

## 结论

已逐一复核 QBZ95、56-1、QBU85、97式防暴霰弹枪、QCQ171 的当前 Run 和真实 UI Before，共 10 状态、270 张原始蒙皮图（每状态9相位×正面/左侧/背面）。这批采样视角中未观察到 M870 那种明显左肩挤细、上臂塌陷或肘部反转；也没有发现本轮对旧枪奔跑带来的动作偏移。此结论不是绝对无问题保证。

## 原始动作保真

- 每状态161相位，逐一核对312个实际Bone对象及枪根局部/世界变换，与 Git 81d5a48 原始基线差异全部为0。人物和五把旧枪GLB字节相同；两个源clip的全部66条轨道完全相同。
- 基线文件逐项校验过Git内容或LFS OID，详见 source-and-baseline.json。
- 所有状态首尾最大骨位差0.044mm、角度0.00649°，未发现接缝突跳证据。
- 各武器的实际身体姿态并不相同，270图没有以同一身体姿态代替渲染。

## 既存行为

97式 Run/Before 会切换clip名，但最终身体/枪姿态基本相同（全周期位置差0，角度差约4e-6°属浮点精度）；原始基线也如此。没有擅自改变这个比较按钮的语义。

## 逐枪观察

- QBZ95：紧凑的胸前携枪，左肩与袖口轮廓保持，手掌随枪，无采样到的明显肩塌或肘反转。
- 56-1：双手间距较宽，肩臂肘轮廓连贯。Before保留原来的较平枪角。
- QBU85：长枪随源奔跑节律倾斜，左肩上臂体积保持，托手在护木下方；上身机位裁掉部分枪口尖端。
- 97式：腰前低持，双肩较放松，采样中握持稳定；Before与当前姿态相同。
- QCQ171：紧凑斜持，采样中肩袖体积保留、手腕与枪的接触一致。

## 证据与边界

联系表：sheets/<weapon>-{current,before}.jpg。本精简包不包含原图、烘焙GLB或临时站点；10张联系表完整保留270张采样视图。coverage-and-findings.json 列出每个状态的证据路径和判读。

实际 Three model.pose(..., compareRun) 输出以240Hz烘焙，再以Blender CPU Cycles渲染原始材质和蒙皮。Before不是无IK控制组。浏览器WebGL不可用，Chromium socket被拒绝后未重试。
